Personal google drive synce for my Obsidian vault
# Obsidian Sync
This page describes the personal Google Cloud app. I created to sync my own Obsidian notes with my own Google Drive, using the community plugin "Vault Sync for Google Drive". It lets me access my notes from my computer and my iphone
# Privacy policy
This app only accesses my own Google Drive files. It does not collect, store, or share data with anyone else. It is for my personal use only.
